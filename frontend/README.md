# AMIRLab Frontend

Next.js public website and private AMIRLab workspace.

## Run

```bash
pnpm install
pnpm run dev
```

Open `http://localhost:3000`. The backend API should be running at the URL configured for the frontend.

## Verify

```bash
pnpm run verify:production
```

Repository rules and implementation constraints are documented in [`../RULES.md`](../RULES.md).
