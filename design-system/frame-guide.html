00 / START

Choose the right owner first

Find the shared component that already owns the layout. Change its props or classes before adding styling to a specific page.

FAST DECISION
Public page?

Use PublicSection for section bays and boundaries. Use PublicShell for the aligned content width.

Workspace page?

Use WorkspaceSurface as the page root and its Hero, Panel, RuleBand, Collection, and Row parts.

Empty / error state?

Use StatePanel. Its frame prop selects public rails, workspace rules, or embedded presentation.

01 / GEOMETRY

Read the frame

Four edges do different jobs. Keep the page-level rails, section rules, side-bay pattern, and padded content in their own layers.

PUBLIC / WORKSPACE
section eyebrow

Section heading lines up with every sibling

Rails define the column. The gutter separates text from the rule. A node marks where the section rule crosses the inner rail.

FrameRailsPublicSectionPublicShell
Outer rail: dashed page edge Inner rail: solid content edge Side bay: pattern between rails Gutter: space between rail and copy Node: rule / rail intersection
Public vs workspace: public pages use dashed outer rails and solid inner rails with patterned side bays. Workspace uses the same solid inner and dashed outer rails, with continuous section bands. The components share frame geometry, but keep the right page family.

import { CollectionHeading, FramedCollection, FramedRow, PublicSection } from "@/components/ui/public-shell";
import { StatePanel } from "@/components/state-panel";

<PublicSection>
  <div className="py-8">
    <CollectionHeading eyebrow="Research outputs" title="Papers" count={papers.length} />

  </div>
</PublicSection>

          06 / SPACING
          

            
Control rail spacing without moving the copy by hand

            

              Column width, side bay, content gutter, and vertical spacing are
              separate controls. Change the shared tokens on the entire frame
              region so the rails and content column move together.
            

          

        

        

          
          
          
          
        

        

          

          

          
          

          

          
          

            Guttered content
            
Move the rails. Keep content aligned.

            

              The tinted strip shows the content gutter. The patterned bay sits
              outside the inner rail.
            

          

        

        

          Apply these tokens to the shared frame region
        

        

        

          The side bay is a minimum, not a fixed width:
          --frame-side caps the outer rail’s inset, so bays may
          grow on wide screens. The column maximum shrinks automatically on
          mobile.
        

        

          

            
              

                Control
                Actual token / class
                Effect and placement
              

            
            
              

                Public column width
                [--public-wide:1240px]!
                
                  Apply on the shared data-site="public" owner. Both PublicShell
                  and FrameRails must inherit the same value.
                
              

              

                Workspace column width
                [--workspace-wide:1080px]!
                
                  Apply to the workspace frame ancestor, above WorkspaceSurface
                  and its FrameRails. The default workspace width is shared
                  across pages.
                
              

              

                Text inset from public rails
                [--public-gutter:2rem]!
                
                  Changes PublicShell’s content padding. FramedCollection uses
                  the same token to cancel that padding for connected rules.
                
              

              

                Text inset from workspace rails
                [--workspace-gutter:1.5rem]!
                
                  Changes WorkspaceSurface, rail sections, band content and rows
                  together. Prefer the shared responsive default.
                
              

              

                Minimum public bay width
                [--frame-band:24px]!
                
                  Distance reserved between outer and inner rails; constrained
                  by the outer inset cap and screen width.
                
              

              

                Outer rail maximum inset
                [--frame-side:3rem]!
                
                  Sets how far the public outer rail can sit from the viewport
                  edge.
                
              

              

                Narrow-screen margins
                
                  --frame-mobile-inner,
                  --frame-mobile-outer
                
                
                  Shared responsive tokens in globals.css. Change both shell
                  geometry and rail geometry together, not a single page’s
                  margin.
                
              

              

                Vertical section space
                
                  contentClassName="py-8",
                  "pt-8 pb-12"
                
                
                  PublicSection and WorkspaceRuleBand accept contentClassName.
                  py-8 = 32px top/bottom; pt-8 pb-12 = 32px top, 48px bottom.
                
              

              

                Space between content items
                grid gap-4, flex gap-3
                
                  Set on the inner content layout; gap-4 = 16px, gap-3 = 12px.
                  This does not move rails.
                
              

              

                Intersection node / dash
                
                  --frame-node-size, --frame-dash
                
                
                  Global frame tokens; node position is derived from size. Keep
                  these shared so intersection marks match everywhere.
                
              

            
          

        

        

          These are existing Tailwind variable utilities:
          square-bracket classes set CSS custom properties; they are not new
          app-specific aliases. Put them on the ancestor that contains both the
          rails and the shell. Changing --frame-inner alone can
          separate the rails from the content width.

Public: rule between rows

            

              Replace a padded child’s border with a FramedCollection and
              FramedRow. Keep padding inside the row.
            

          

          

            

              Inner rail → inner rail
            

            
import { FramedCollection, FramedRow, PublicSection } from "@/components/ui/public-shell";

<PublicSection contentClassName="py-8">
  <FramedCollection topRule>
    <FramedRow className="px-[var(--public-gutter)] py-5">
      ...first row...
    </FramedRow>
    <FramedRow className="px-[var(--public-gutter)] py-5">
      ...second row...
    </FramedRow>
  </FramedCollection>
</PublicSection>

          

        

        

          

            
Public: section boundary

            

              Use the section’s boundary prop for a line spanning the page,
              including the side bays and intersection nodes.
            

          

          

            

              Page edge → page edge
            

            
<PublicSection bay="plus" boundary="bottom" contentClassName="py-10">
  ...section content...
</PublicSection>

{/* For a custom stroke, omit boundary and use FrameRule. */}
<PublicSection contentClassName="py-10">
  ...section content...
  <FrameRule edge="bottom" stroke="dashed" />
</PublicSection>

          

        

        

          

            
Workspace: content band

            

              Use a band for controls or a collection for repeated rows. Both
              join the workspace rails automatically.
            

          

          

            

              Workspace rails
            

            
import { WorkspaceRuleBand, WorkspaceCollection, WorkspaceRow } from "@/components/ui/workspace-surface";

<WorkspaceRuleBand contentClassName="py-4">
  ...controls...
</WorkspaceRuleBand>
<WorkspaceCollection>
  <WorkspaceRow className="py-4">...row one...</WorkspaceRow>
  <WorkspaceRow className="py-4">...row two...</WorkspaceRow>
</WorkspaceCollection>

          

        

        

          

            
              

                Desired line
                Use
                Padding rule
              

            
            
              

                Within an inset content group
                border-b border-line
                
                  Child border stays inside parent padding; appropriate for a
                  local field-group divider.
                
              

              

                Public inner rails
                FramedCollection + FramedRow
                
                  Collection cancels the public gutter once. Row content adds
                  that gutter back.
                
              

              

                One independent public row
                FramedRow bleed
                
                  Use bleed inside padded PublicShell only. Do not also put that
                  row inside a bleeding FramedCollection.
                
              

              

                Full page with nodes
                PublicSection boundary="bottom"
                
                  No extra border on the inner content. FrameRule owns the line
                  and nodes.
                
              

              

                Workspace band / repeated rows
                
                  WorkspaceRuleBand /
                  WorkspaceCollection
                
                
                  Band owns the inner gutter. WorkspaceRow’s default inset owns
                  row padding.
                
              

            
          

        

        

          Common fixes: a line stops early → move the border to
          the rail-level owner. Copy touches a rail → add the shared gutter to
          the inner content. A line overshoots → remove a second bleed wrapper.
          A rule looks twice as thick → remove the duplicate border at the same
          edge.
        

      


      

        

          08 / YOUR FIX
          

            
A safe workflow for small UI changes

            

              Use this sequence when you make the next refinement yourself. It
              keeps the change local while preserving the shared system.
            

          

          CHECKLIST
        

        
    
          
  1. 
            Find the component. Search for the page title or
            current UI, then find the shared component it renders.
          
    2. 
          
  2. 
            Pick the right owner. Public shell for public
            pages; workspace surface for workspace pages; StatePanel for status
            content.
          
    3. 
          
  3. 
            Make the smallest prop/class change. Prefer a
            shared prop. Keep the rail geometry and content gutter owned by the
            component.
          
    4. 
          
  4. 
            Check its callers. If changing a shared component
            or CSS class, search all usages so sibling pages don’t regress.
          
    5. 
          
  5. 
            Check two widths. One desktop viewport and one
            narrow mobile width; verify headings, both rails, and no horizontal
            overflow.
          
    6. 
          
  6. 
            Check neighboring states. Loading, empty, error,
            and populated views should keep the same layout and section heading.
          
    7. 
        

        

          Useful searches:
rg -n "ComponentName" frontend/src
rg -n "frame-rail-section|frame-stroke-|frame-.*-hatch"
            frontend/src frontend/public
